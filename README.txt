PORTFOLIO WITH THREE THEMES

Files:
- index.html
- style.css

Features:
- Dark, Light, and Natural theme buttons in the navigation bar.
- Education and Certificates displayed in separate side-by-side columns.
- JDBC and Servlets added under Core Concepts.
- Responsive layout and mobile navigation.

To use:
1. Keep index.html and style.css in the same folder.
2. Open the folder in VS Code.
3. Open index.html in your browser, or run it with Live Server.
4. Click Dark, Light, or Natural in the top navigation to switch themes.
